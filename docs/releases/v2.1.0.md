# v2.1.0

### Changes

- Add read-only HTTPS Git proxy support for public GitHub repositories, including `clone`, `fetch`, and `pull`.
- Support Git Smart HTTP protocol v0/v2 and shallow clones while preserving Git headers and binary request/response bodies.
- Restrict POST requests to `git-upload-pack` and reject push services and unsupported Git redirects.
- Keep existing file downloads and attachment filenames intact; add clone examples to the README and API documentation.

### Validation

- Typecheck and read-only Biome check passed.
- 109 unit/component tests passed.
- 24 desktop/mobile end-to-end tests passed, including accessibility checks.
- Vite production build and Wrangler dry-run passed.

### Known limitation

- The Safari production download routing fix (P16) remains pending. This release does not include a production deployment or claim that issue is resolved.
