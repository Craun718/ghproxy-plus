# v2.1.1

### Changes

- Display the GPP version and UTC build date in the shared footer on all pages.
- Read the version from `package.json` and inject the build time during the Vite build.
- Show the complete ISO build timestamp on hover and support narrow screens.

### Validation

- Typecheck, read-only Biome check, 109 unit/component tests and production build passed.
- The footer feature passed 24 desktop/mobile end-to-end tests and production preview checks at 1280px and 320px before this version bump.

### Known limitation

- The Safari production download routing fix (P16) remains pending. This release preparation does not include a production deployment.
